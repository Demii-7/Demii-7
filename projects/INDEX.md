# Project Archive Index

This folder stores recovered source material and original submission files for later repository-by-repository cleanup.

## 1. Demii-7.github.io
- Static website project.
- Contains: `index.html`, `styles.css`, `script.js`, `README.md`, `assets/` placeholders, `.gitignore`.

## 2. Digital Logic
- Digital logic course artifacts.
- Contains: three PDF lab reports and three `.cv` files.
- The `.cv` files are JSON-based circuit/project files.

## 3. GSR Fear Index
- MATLAB-based GSR fear analysis project.
- Contains: `Fear_Analyzer.m`, feature extraction and filtering scripts, normalization/data-loading helpers, and one case-study `.docx`.

## 4. Iteraed Prisoner's Dilemma
- C++ iterated prisoner's dilemma project.
- Contains: `Iterated_Prisoners’s_Dilemma.cpp`, `Game.h`, `Player.h`, `Strategy.h`, and one case-study `.docx`.

## 5. Lab 2_Part_1_as18181_dsw9740
- Digital logic / FPGA tail light submission package.
- Contains: one demo `.mp4`, one report `.pdf`, and `Tail_Light.zip`.
- `Tail_Light.zip` contains: `FSM.vhd`, `Part3Testbench.vhd`, `basys2.ucf`, `Tail_Light.xise`, generated Xilinx ISE files, and `iseconfig/` reports.

## 6. Lab 2_Part_2_as18181_dsw9740
- Digital logic / FPGA traffic controller submission package.
- Contains: one demo `.mp4`, one report `.pdf`, and `Lab2_Traffic_Controller.zip`.
- `Lab2_Traffic_Controller.zip` contains: `FSM.vhd`, `Testbench.vhd`, `basys2.ucf`, `Lab2_Traffic_Controller.xise`, generated Xilinx ISE files, and `iseconfig/` reports.

## 7. Lab_3_as18181_dsw9740
- Digital logic / FPGA ALU and display submission package.
- Contains: one report `.pdf` and `Lab3.zip`.
- `Lab3.zip` contains: `ALU.vhd`, `ALU_display.vhd`, `single_number.vhd`, `.sym` symbol files, `display.ucf`, `Lab3.xise`, generated Xilinx ISE files, and `iseconfig/` reports.

## 8. Seawater linear Regression
- C++ linear regression project for seawater freezing temperature estimation.
- Contains: `LRS_salinity_temp.cpp` and one civil engineering case-study `.docx`.

## 9. Thermal Dissipation
- C++ thermal distribution simulation project.
- Contains: `thermal_dist_simulator.cpp` and one mechanical engineering case-study `.docx`.

## 10. Circuits
